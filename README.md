# Skerdian Shehaj — Portfolio

A simple, responsive personal portfolio built with HTML and CSS. No dependencies, build step, JavaScript, API keys, or environment variables are required.

## Contents

- Introduction and core skills
- Three public projects with GitHub source links
- Professional background and areas of focus
- GitHub, LinkedIn, and email contact links

## Edit

- Update content and links in `index.html`.
- Adjust colors, spacing, and responsive layouts in `styles.css`.
- Replace `favicon.svg` to change the browser icon.

## Run locally

From the repository root:

```sh
python -m http.server 8000
```

Open http://localhost:8000.

## Deploy on Vercel

Import this GitHub repository using the Other framework preset. Leave the build and install commands empty; serve the repository root. `vercel.json` contains these settings. The connected production branch is `master`.

The existing `CNAME` file is preserved for the repository's separate GitHub Pages configuration. Vercel domains are managed independently.
